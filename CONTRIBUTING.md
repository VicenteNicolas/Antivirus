# Contribuir

Usa ramas independientes para cambios de riesgo y commits descriptivos como `feat:`, `fix:`, `test:` y `docs:`. En Windows x64, ejecuta la restauración bloqueada, la compilación Release y toda la suite antes de proponer cambios. Actualiza el changelog, el roadmap y la documentación que afecte al usuario.

Usa archivos sintéticos inofensivos en las pruebas. Mantén credenciales, bases personales, archivos de cuarentena, ejecutables descargados y muestras fuera de Git. La prueba opcional EICAR usa una ruta proporcionada por el entorno y no genera muestras.
