# Seguridad de Sentinel Security

Para reportar una vulnerabilidad, usa el canal privado de seguridad del repositorio si está habilitado. Si necesitas solicitar un canal de contacto, abre una incidencia pública sin detalles de explotación ni datos del equipo.

Incluye versión, Windows y pasos seguros de reproducción. Reemplaza nombres de archivo y rutas privadas por ejemplos. Mantén el software y las firmas externos actualizados. El funcionamiento normal se prueba con Defender activo y con una cuenta estándar.
